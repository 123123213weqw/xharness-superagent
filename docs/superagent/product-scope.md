# 产品范围：只复刻产品逻辑

生效日期：2026-11-01。此决定取代旧计划对 JavaScript 语言全域等价的要求。

## 保留的产品目标

- 事件接入、过滤、评估、授权、任务创建与执行、回复和状态查询。
- 主角色/Worker 的工具权限、Prompt/skills、停止/重试/后台任务生命周期。
- 持久化、业务幂等、崩溃恢复、GitHub/飞书、配置、管理面板与部署。
- 正常中文、英文、emoji、常见时间与时区的正确处理。
- 不改变旧 XHarness 的默认权限、沙箱或已有会话行为。

## 已取消，不是发布前置条件

- 模拟 JavaScript 任意字符串/数值/日期输入的全部语言语义。
- 为未配对 UTF-16 代理项在所有 Message/Source/API 路径迁移内部类型。
- 所有 IANA 时区远未来规则、所有历史 V8 日期语法的逐点等价。
- 没有实际产品影响证据的 JSON 表示细节逐字节等价。

已完成且被业务代码使用的局部解析/编码辅助函数保留，不做高风险的盲目删除；
它们不再扩大为全域兼容任务，也不作为产品完成度。业务 ID、授权身份、
真实 Prompt/工具内容或外部协议依赖的表示行为仍需正确，不能借此忽略实际回归。

## 当前发布边界

发布树从 xharness-runtime 集成工作副本整理，不包含 canonical 工作副本中
尚未接入 Runtime 的全链路 UTF-16 类型迁移。该实验留在本地，不合并、不发布。
因误认 SDK schemas() 为实际模型装配路径而新增的可选工具注册顺序实验已撤回；
保留原有按名称排序的 Registry 行为，不实施未经证实的 Zod 元数据修复。

当前是开发版源码，不是完整可运行的 SuperAgent 替代品。组件测试不等于
产品端到端验收。conformance/rubric.json 和 backlog.json 是原严格计划的历史
清单，96 项均未验收，不得将取消范围记成通过；后续按本文件重审产品场景。
